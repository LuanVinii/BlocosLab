# Ícones Lucide

Os ícones desta pasta vêm do pacote `lucide-static` versão 1.65.0.
Fonte: https://github.com/lucide-icons/lucide
Licença: ISC. O texto integral está no arquivo `LICENSE` desta pasta.

Os arquivos usam a geometria oficial dos ícones Puzzle, Image, Maximize, Minimize, Blocks, Layers 2, Audio Lines, Play e Square. As cores foram ajustadas para a interface BlocosLab.

Também foram adicionados os ícones Image Plus e Zap da mesma biblioteca e versão.
